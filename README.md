## 4. 최종 산출물

### 프로젝트명: 영어학습 여행앱
 
#### 화면 1: 메인 홈 화면
 - 원형 프로그레스 바로 오늘의 학습 목표 달성률(예: 75%) 표시
 - 여행 D-day 위젯 (예: "뉴욕까지 D-15") + 목적지 아이콘

#### 화면 2: 카테고리 화면
  - 여행 상황별 학습 분류: 공항 / 호텔 / 음식 / 쇼핑
  - 2×2 카드 그리드 형태로 직관적 선택

#### 화면 3: 학습 화면 (플래시카드)
  - 영단어 + IPA 발음기호 표시 (예: RESERVATION /ˌrezərˈveɪʃən/)
  - 발음 듣기(스피커) · 즐겨찾기(별) 기능
  - 스와이프 학습: O(암기 완료) / X(다시 학습)

#### 화면 4: 리더보드 화면
  - 학습 포인트 기반 랭킹 시스템
  - TOP 3 메달(금·은·동) 강조
  - 표 형식: 순위 / 이름 / 학습 포인트

#### 화면 5: 설정 화면
  - 일일 학습 목표 설정 (예: 20단어)
  - 여행 목적지 / 여행 날짜 설정
  - 알림 ON/OFF · 다크 모드 토글
