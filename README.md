### 1.2 서비스 한 줄 정의

> **Travoca — 여행자를 위한 목적지 맞춤 외국어 학습 앱**
> "Travel" + "Voca"의 합성어. 해외여행을 앞둔 사용자가 여행 D-Day에 맞춰, 목적지에 따라 자동으로 학습 언어가 결정되는(예: 뉴욕 → 영어, 파리 → 프랑스어) 상황별(공항, 호텔, 음식, 쇼핑) 단어를 게임처럼 학습할 수 있도록 돕는 서비스

## 2. 서비스 기획

### 2.1 타겟 사용자
- 해외여행을 앞둔 20~30대
- 여행지에서 바로 쓸 수 있는 실용 외국어(공항, 숙소, 식당, 쇼핑 상황)를 빠르게 학습하고 싶은 사용자

### 2.2 핵심 문제
- 기존 어학 앱은 여행이라는 구체적 맥락 없이 범용 단어를 학습시켜 동기부여가 약함
- 여행지마다 필요한 언어가 다른데, 매번 학습 언어를 직접 선택·설정해야 하는 번거로움이 있음
- 여행 출발일이 다가올수록 학습 긴장감(D-Day)을 시각적으로 자극할 장치가 부족함

### 2.3 핵심 기능
- **목적지 기반 언어 자동 매칭**: 설정에서 여행 목적지를 입력하면 학습 언어가 자동으로 결정됨 (예: 뉴욕 → 영어, 파리 → 프랑스어, 도쿄 → 일본어)
- **메인 학습화면**: 오늘의 학습 진행률, 여행 D-Day 표시
- **학습 카테고리**: 공항 / 호텔 / 음식 / 쇼핑 등 여행 상황별 단어장
- **학습 화면**: 플래시카드 형태의 단어 학습 (발음기호 포함)
- **랭킹(리더보드)**: 학습 포인트 기반 순위
- **설정**: 일일 학습 목표, 여행 목적지·날짜(→학습 언어 결정), 알림, 다크모드

### 2.4 다국어 확장 구조
Travoca는 특정 언어(영어)에 종속된 서비스가 아니라, **목적지 → 언어 매핑 테이블**을 기반으로 하는 구조로 설계되었습니다.

| 목적지 | 학습 언어 |
|---|---|
| 뉴욕, 런던 | 영어 |
| 파리 | 프랑스어 |
| 도쿄 | 일본어 |
| (목적지 추가 시) | (해당 언어 자동 매칭) |

사용자가 설정 화면에서 여행 목적지를 지정하면, 카테고리(공항/호텔/음식/쇼핑)별 단어 콘텐츠가 목적지에 대응하는 언어로 자동 전환되는 구조이며, 콘텐츠 데이터베이스만 언어별로 확장하면 신규 목적지·언어 추가가 가능합니다.

> ※ 본 보고서의 UI 시안 이미지는 대표 예시로 **목적지 "뉴욕(영어)"** 기준으로 제작되었으며, 실제 서비스에서는 위 구조에 따라 목적지별 언어로 콘텐츠가 전환됩니다.

## 3. AI 활용 UI 생성 과정

### 3.1 사용 도구
- 이미지 생성: **IMAGE 2**(1개 프롬프트로 5개 화면 일괄 생성) → **나노바나나(Nanobanana)** (메인 홈 화면 수정에만 사용, 한국어 프롬프트로 재작업)
- 프로토타입: Figma / Figma Make

### 3.2 프롬프트 개선 과정 (초안 → 수정 → 최종)

| 단계 | 주요 변경 내용 | 변경 이유 및 결과 |
|---|---|---|
| 초안 | IMAGE 2에 하나의 프롬프트로 5개 화면(홈/카테고리/학습/랭킹/설정)을 한 번에 요청하여 일괄 생성 | 한 번에 여러 화면을 뽑을 수 있어 속도는 빨랐으나, 화면마다 톤·여백·목업 프레임 형태가 제각각으로 나와 세트로서의 일관성이 낮음 (예: 홈만 입체 프레임, 나머지는 평면) |
| 수정 1 | 홈 화면만 나노바나나(Nanobanana)로 전환, 한국어 프롬프트로 세부 요소(D-Day 배지, 통계 카드, CTA 버튼 등)를 문장 단위로 상세 기술하여 재생성 | 영문 키워드 나열 방식보다 한국어 서술형 프롬프트가 한글 UI 텍스트·레이아웃 의도를 더 정확히 전달함. 홈 화면의 정보 밀도(D-Day, 진행률, 스트릭/포인트 카드, CTA)가 명확하게 구조화됨 |
| 최종 | 나머지 4개 화면(카테고리/학습/랭킹/설정)도 동일한 톤으로 개별 영문 프롬프트를 세밀화(px 단위 수치 명시)하여 5화면 세트로 통일, 아이폰 목업 프레임 통일 | 화면 세트로서의 일관성 확보, 학습 동기부여 요소(스트릭, 포인트) 시각화 강화 |

### 3.3 화면별 생성 이미지

1. **메인 홈**: 학습 목표 달성률(75%), 여행 D-Day 배지, 연속 학습일·포인트 카드, CTA 버튼
2. **카테고리**: 공항/호텔/음식/쇼핑 2x2 그리드
3. **단어 학습**: 플래시카드(단어 + 발음기호), 정답 확인 버튼
4. **랭킹**: TOP 3 시상대 + 순위표(순위/이름/학습 포인트)
5. **설정**: 학습 목표, 여행 목적지·날짜, 알림, 다크모드 토글
